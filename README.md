🌐 Health & Calorie Recommendation System(FIT MAKER)
 🛠️ Technologies: HTML, CSS, Bootstrap, JavaScript, Python, SQLite
 📦 Framework: Django | 📊 Library: Pandas
Built a secure and intelligent web platform that offers personalized diet and fitness recommendations based on user input and health conditions.
🔑 Key Features:
🔒 1. Secure Login System
Implements a robust authentication mechanism to ensure user data is protected.
Provides personalized access and session management.
🥗 2. Calorie Calculation Based on Food Intake
Users can input the food they’ve eaten along with its quantity.
The system calculates the total calorie intake using a food database and performs data analysis with Pandas.
🏋️‍♀️ 3. Personalized Exercise Recommendations
Based on the calculated calorie intake, the system recommends suitable exercises.
Also provides an estimated duration needed to burn the consumed calories.
🩺 4. Disease-Aware Food Suggestions
Users can specify health conditions such as Diabetes and its severity level.
The system intelligently suggests which foods are safe and which to avoid, tailored to the selected disease.
❤️ 5. Condition-Specific Fitness Guidance
For users with heart-related issues, the system recommends exercises that are safe and flags those that may be risky.
Helps ensure fitness routines align with the user's health limitations.
